# Project Statement

## Problem Statement
Teachers and academic administrators often need to maintain student information, attendance, and marks in a consistent way. Managing these details manually can make searching, updating, calculating attendance, and preparing performance summaries repetitive.

The **Smart Student Performance & Attendance Manager** provides a command-line Java solution for storing student records, recording attendance, managing marks, and producing simple academic summaries.

## Scope
The project covers:
- Student CRUD operations
- Attendance calculation
- Marks entry and average calculation
- Grade calculation
- Performance reporting
- CSV-based persistent storage
- Input validation and error handling

The project does not attempt to replace a complete institutional ERP system, online authentication system, or cloud database.

## Target Users
- Teachers
- Academic coordinators
- Small training/coaching institutes
- Students demonstrating Java programming concepts

## High-Level Features
- Add/search/update/delete students
- Record attendance
- Add subject marks
- Calculate average and grade
- Generate performance report
- Show students below 75% attendance
- Save/load records using CSV
- Handle invalid input and file errors
